# ui8px policy

Generated by `npx ui8px init` (bundled defaults: 8 px layout steps, 4 px steps inside controls). Additions to
`allowed.json` `utilities` (spacing scales unchanged): the token rings `inset-ring`, `inset-ring-input`,
`inset-ring-ring` (since ui8px 0.2.5 `inset-ring*` is a ring utility, not `inset-*` spacing) and non-spacing utilities
used by the Console: `auto-rows-min`, `underline`, `underline-offset-4`, `uppercase`, `border-b`,
`break-words`, `align-middle`, `min-h-screen`, `max-h-screen` (viewport units, not px). Form controls use
`af.InputSkin` / `af.LabelSkin`. Console code
stays in layout scope; ring, control padding and badge/alert/card recipes come from the authkit Authfly skin
(`af.*Skin`). `npx ui8px@0.2.5 lint` runs in `bun run test`.
